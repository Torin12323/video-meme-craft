# video-meme-craft

> 短视频链接 → 梗图描述词，一键自动化

## 这是什么

粘贴一个短视频分享链接（抖音/快手/小红书/视频号），自动完成：

1. **提取视频文案**（标题 + 简介 + 口播）
2. **提炼核心矛盾/笑点**
3. **套用 A–G 框架**生成完整描述词
4. **输出 4 个纯文本代码块**（拆解表 + 描述词 + 规范模板 + 使用流程）

输出的描述词可直接喂给 AI 绘图工具生成梗图。

## 快速使用

```
# 直接发一个视频链接
https://v.douyin.com/xxxxxxx/

# 或加一句说明
https://v.douyin.com/xxxxxxx/ 帮我做个梗图

# 想改参数？附带说明即可
https://v.douyin.com/xxxxx/ 帮我做个正方形的，1倍导出
```

## A–G 框架

| 点 | 角色 | 说明 |
|---|------|------|
| A | 原始素材 | 视频文案提炼后的核心矛盾/笑点 |
| B | 生成指令 | 声明"按以下 C–G 生成图片" |
| C | 尺寸约束 | 默认 1920×1080（16:9, Full HD） |
| D | 文字内容 | 主标题 ≤12字 + 副文案 ≤25字 |
| E | 插画元素 | 2~4 个核心视觉元素 |
| F | 视觉处理 | 保证文字可读（暗条压底等） |
| G | 导出规格 | 默认 2× 高清（3840×2160），PNG |

## 默认参数

| 参数 | 默认值 |
|------|--------|
| 尺寸 | 1920×1080（16:9） |
| 导出倍率 | 2× 高清（3840×2160） |
| 风格 | 扁平矢量插画风，幽默吐槽 |
| 暗条 | 上下深色暗条压底 |
| 元素数量 | 2~4 个 |
| 格式 | PNG |

## 安装

将本目录复制到 OfficeClaw 技能目录：

```bash
cp -r video-meme-craft ~/.office-claw/skills/
```

或直接放入 `<office-claw>/.office-claw/skills/` 目录下。

## 依赖

- `douyin-copy-extract` 技能（用于短视频链接文案提取）
- 如不可用，降级为手动粘贴文案模式

## 设计原则

- **自主跑完**：不需逐步确认，一次输出全部 4 个代码块
- **纯文本优先**：所有输出用代码块包裹，方便一键复制
- **矛盾驱动**：梗图核心是矛盾/反差，Step 2 是关键
- **元素克制**：插画元素不超过 4 个，避免画面杂乱
- **文字优先**：文字可读性 > 视觉花哨

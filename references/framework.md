# A–G 框架详细定义

> 版本 v1.1 · 2026-08-15

## 框架总览

A–G 框架是梗图生成的标准化七点结构，从素材到导出全覆盖。

| 点 | 角色 | 核心问题 |
|---|------|---------|
| A | 原始素材 | 梗从哪来？矛盾点是什么？ |
| B | 生成指令 | 给 AI 绘图工具的指令声明 |
| C | 尺寸约束 | 发在哪？多大？ |
| D | 文字内容 | 说什么？怎么说得扎心？ |
| E | 插画元素 | 画什么？几个元素？怎么排？ |
| F | 视觉处理 | 怎么保证文字看得清？ |
| G | 导出规格 | 存哪？多大分辨率？什么格式？ |

## 各点详细规则

### A. 原始素材

- 来源：视频文案提炼 / 新闻 / 段子 / 用户直接输入
- 提炼目标：找到核心矛盾或反差
- 长度：≤30 字
- 多图模式：若生成多张图片，为每张提炼不同的矛盾点/笑点
- 示例：「看看现在的显卡行情，N卡涨完A卡涨，耕升、七彩虹、微星一个没跑，内存、固态、主板全线飘红。」

### B. 生成指令

- 固定文案："按照以下 C–G 要求生成图片"
- 作用：明确告知 AI 绘图工具后续各点都是约束条件

### C. 尺寸约束

| 用途 | 尺寸 | 比例 |
|------|------|------|
| 公众号/小红书横版 | 1920×1080 | 16:9 |
| 朋友圈/小红书竖版 | 1080×1920 | 9:16 |
| 头像/正方形 | 1080×1080 | 1:1 |
| 公众号封面 | 900×383 | 2.35:1 |

默认：1920×1080（16:9 横版，Full HD）

### D. 文字内容

- 主标题：≤12 字，点睛用，加粗大字
- 副文案：≤25 字，解释/吐槽/反问，小字
- 排版规则：
  - 主标题居中或偏上，副文案在主标题下方
  - 字体推荐：思源黑体 / 阿里巴巴普惠体
  - 颜色：根据整体风格和背景灵活选择，保证可读性

### E. 插画元素

- 数量：2~4 个（超过 4 个画面杂乱）
- 每个元素需描述：
  - 角色（人/物/图标）
  - 动作/表情
  - 道具/装饰
- 排列方式：左中右 / 上下 / 居中 / 散点
- 风格：根据内容自动匹配（见下方"风格匹配规则"）

### F. 视觉处理

- 文字可读性：保证主标题和副文案在任何背景上都清晰可读
- 处理方式根据风格和内容灵活选择，不限定单一手法：
  - 纯色背景 + 高对比文字
  - 渐变背景 + 描边文字
  - 图文分区排版
  - 半透明遮罩局部压底
  - 其他创意排版
- 插画区：背景色 + 饱和度 + 明暗对比，根据风格调整
- 文字层级：主标题 > 副文案 > 标签
- 配色方案：
  - 主色：1 个（确定基调）
  - 辅色：1~2 个（丰富层次）
  - 警示色：1 个（强调矛盾，如红色）
  - 背景色：1 个（衬托主体）

### G. 导出规格

- 文件路径：`outputs/<梗图名称>.png`
- 倍率：
  - 1× = 原始尺寸（适合快速预览）
  - 2× = 双倍尺寸（适合公众号/小红书，默认）
  - 3× = 三倍尺寸（适合印刷或大屏展示）
- 格式：PNG（无损）或 JPG（有损但体积小）
- 质量等级：如用 JPG，建议 90%+

## 风格匹配规则

风格不固定，根据视频内容自动匹配：

| 内容类型 | 推荐风格 | 特点 |
|----------|---------|------|
| 科技/硬件吐槽 | 扁平矢量插画风 | 线条简洁，色块明快 |
| 生活/情感类 | 手绘水彩风 | 笔触柔和，色调温暖 |
| 职场/社会现象 | 美式漫画风 | 粗线条，夸张表情 |
| 搞笑/反转类 | Q版卡通风 | 圆润造型，表情夸张 |
| 知识/科普类 | 信息图风格 | 图标+数据可视化 |
| 愤怒/吐槽类 | 波普艺术风 | 高对比度，冲击力强 |

- 以上为参考，实际风格根据内容自由选择
- 用户可指定风格覆盖
- 同一组图片可混合不同风格

## 图片数量计算规则

根据视频时长动态决定生成图片数量：

| 视频时长 | 建议图片数 | 说明 |
|----------|-----------|------|
| ≤ 15 秒 | 2~3 张 | 短视频内容精简，抓核心即可 |
| 16~30 秒 | 4~6 张 | 有一定叙事，可分段描述 |
| 31~60 秒 | 7~10 张 | 内容较丰富，按段落拆分 |
| 1~3 分钟 | 10~20 张 | 长视频按内容节点拆分 |
| > 3 分钟 | 20~30 张 | 深度内容，按主题段落拆分 |

- 基准规则：约每 6~8 秒内容生成 1 张图片
- 内容密度高则多生成，节奏舒缓则少生成
- 用户可指定数量覆盖

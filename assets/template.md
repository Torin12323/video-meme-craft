## 代码块 3: 规范框架

```
┌───────────────────────────────────────────┐
│         梗图生成规范 v1.1                  │
├───────────────────────────────────────────┤
│                                           │
│  A. 素材原文                               │
│     → 梗的文字来源/新闻/段子                │
│     → 提炼核心矛盾点                        │
│     → 多图模式：每张图不同矛盾点             │
│                                           │
│  B. 生成指令                               │
│     → 声明"按以下 C–G 生成图片"            │
│                                           │
│  C. 尺寸约束                               │
│     → 宽×高 + 比例（16:9 / 1:1 / 9:16）    │
│     → 用途场景（公众号/朋友圈/小红书）       │
│                                           │
│  D. 文字内容                               │
│     → 主标题：≤12字，点睛用                │
│     → 副文案：≤25字，解释/吐槽/反问         │
│     → 标注字体、字号、颜色                  │
│                                           │
│  E. 插画元素                               │
│     → 2~4 个核心视觉元素                   │
│     → 每个元素：角色/动作/道具/表情         │
│     → 排列：左中右 / 上下 / 居中            │
│     → 风格：根据内容自动匹配                │
│                                           │
│  F. 视觉处理                               │
│     → 保证文字清晰可读                      │
│     → 处理方式灵活选择，不限定单一手法       │
│     → 文字层级：主标题>副文案>标签          │
│     → 配色：主色/辅色/警示色/背景色         │
│                                           │
│  G. 导出规格                               │
│     → 文件路径+文件名                      │
│     → 倍率（1×/2×/3×）                     │
│     → 格式（PNG/JPG）+ 质量等级            │
│                                           │
└───────────────────────────────────────────┘
```

## 代码块 4: 使用流程

```
1. 填入 A（素材）      → 提炼矛盾/笑点
2. 确认 C（尺寸）      → 根据发布平台选择
3. 撰写 D（文字）      → 主标题抓眼球，副文案补刀
4. 设计 E（插画）      → 元素不超过 4 个，避免杂乱
5. 设定 F（处理）      → 保证文字清晰可读
6. 指定 G（导出）      → 2× 高清是公众号/小红书最低要求
7. 拼合完整描述词      → 喂给 AI 绘图工具生成
```

## 风格匹配参考表

```
内容类型            → 推荐风格
─────────────────────────────────────
科技/硬件吐槽       → 扁平矢量插画风
生活/情感类         → 手绘水彩风
职场/社会现象       → 美式漫画风
搞笑/反转类         → Q版卡通风
知识/科普类         → 信息图风格
愤怒/吐槽类         → 波普艺术风
─────────────────────────────────────
* 以上为参考，根据内容自由选择
* 用户可指定覆盖
* 同组图片可混合风格
```

## 图片数量计算参考表

```
视频时长        → 建议图片数
─────────────────────────────────
≤ 15 秒         → 2~3 张
16~30 秒        → 4~6 张
31~60 秒        → 7~10 张
1~3 分钟        → 10~20 张
> 3 分钟        → 20~30 张
─────────────────────────────────
基准：约每 6~8 秒内容生成 1 张
* 用户可指定数量覆盖
```

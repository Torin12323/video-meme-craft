# 梗图生成规范 v1.0 — 可复用模板

> 将以下模板中的 `<...>` 替换为实际内容即可使用。

## 代码块 1: 各点内容拆解表

```
A|原始素材|<提炼后的矛盾点，≤30字>
B|生成指令|按照以下 C–G 要求生成图片
C|尺寸约束|<宽>×<高>（<比例>，<用途>）
D|文字内容|主标题「<≤12字>」+ 副文案「<≤25字>」
E|插画元素|<元素1>、<元素2>、<元素3>
F|视觉处理|<暗条/边框描述>，<插画区描述>，<文字层级>
G|导出规格|outputs/<文件名>.png，<N>×高清（<实际宽>×<实际高>）
```

## 代码块 2: 图片生成描述词模板

```
画面尺寸：<宽>×<高>像素，<比例>横版/竖版

整体风格：扁平矢量插画风，幽默吐槽气质，线条简洁，色块明快

构图布局：
- 上下深色暗条（高度占比 15~25%），用于承载文字
- 中间为插画区，背景鲜亮，元素排布清晰

文字排版：
- 主标题：「<标题>」
  位置：居中偏上，字号 72pt，加粗，白色
- 副文案：「<副文案>」
  位置：主标题下方，字号 36pt，常规，浅灰

插画元素（共 <N> 个）：
1. <元素1描述：角色+动作+道具+表情>
2. <元素2描述>
3. <元素3描述>

配色方案：
- 主色：<色名+色值>
- 辅色：<色名+色值>
- 警示色：<色名+色值>（用于强调矛盾）
- 背景色：<色名+色值>

导出参数：
- 分辨率：<实际宽>×<实际高>（<N>×高清）
- 格式：PNG
- 文件名：<文件名>.png
```

## 代码块 3: 规范框架

```
┌───────────────────────────────────────────┐
│         梗图生成规范 v1.0                  │
├───────────────────────────────────────────┤
│                                           │
│  A. 素材原文                               │
│     → 梗的文字来源/新闻/段子                │
│     → 提炼核心矛盾点                        │
│                                           │
│  B. 生成指令                               │
│     → 声明"按以下 C–G 生成图片"            │
│                                           │
│  C. 尺寸约束                               │
│     → 宽×高 + 比例（16:9 / 1:1 / 9:16）    │
│     → 用途场景（公众号/朋友圈/小红书）       │
│                                           │
│  D. 文字内容                               │
│     → 主标题：≤12字，点睛用                │
│     → 副文案：≤25字，解释/吐槽/反问         │
│     → 标注字体、字号、颜色                  │
│                                           │
│  E. 插画元素                               │
│     → 2~4 个核心视觉元素                   │
│     → 每个元素：角色/动作/道具/表情         │
│     → 排列：左中右 / 上下 / 居中            │
│                                           │
│  F. 视觉处理                               │
│     → 暗条/边框：位置+颜色+高度占比         │
│     → 插画区：背景+饱和度+明暗              │
│     → 文字层级：主标题>副文案>标签          │
│     → 配色：主色/辅色/警示色/背景色         │
│                                           │
│  G. 导出规格                               │
│     → 文件路径+文件名                      │
│     → 倍率（1×/2×/3×）                     │
│     → 格式（PNG/JPG）+ 质量等级            │
│                                           │
└───────────────────────────────────────────┘
```

## 代码块 4: 使用流程

```
1. 填入 A（素材）      → 提炼矛盾/笑点
2. 确认 C（尺寸）      → 根据发布平台选择
3. 撰写 D（文字）      → 主标题抓眼球，副文案补刀
4. 设计 E（插画）      → 元素不超过 4 个，避免杂乱
5. 设定 F（处理）      → 保证文字可读
6. 指定 G（导出）      → 2× 高清是公众号/小红书最低要求
7. 拼合完整描述词      → 喂给 AI 绘图工具生成
```
